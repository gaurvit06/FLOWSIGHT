# Model card: FlowSight `xgb`

Trained 2026-11-25 18:07:44 UTC. Generated by `scripts/model_card.py` from the saved model metadata.

## Intended use
- Classify network **flows** (CICFlowMeter features) as Benign, BruteForce, DDoS, DoS, PortScan, and flag flows unlike any benign traffic as `Unknown-Anomaly`.
- Decision support for a human analyst: every alert carries a plain-English explanation, a severity and an incident grouping.
- **Not** an inline firewall/IPS: it never blocks traffic.

## Out of scope
- Encrypted payload inspection (only flow statistics are used).
- Networks very different from the training data without retraining (see the drift monitor and the cross-dataset report).

## Training data
CIC-IDS2017 (see `reports/DATASET.md`). Identifiers (IPs, source port, flow ID, timestamp) are removed; duplicates removed before splitting.
Stratified split: train 600,000 / validation 377,499 / test 377,499 flows (seed 42). The model was **chosen on validation** and evaluated **once** on test.

## Model
- Pipeline: StandardScaler → top-20 feature selection (`tree`) → xgb
- Selected features: Destination Port, Flow Duration, Bwd Packet Length Max, Bwd Packet Length Mean, Bwd Packet Length Std, Flow IAT Max, Fwd IAT Std, Fwd IAT Max, Max Packet Length, Packet Length Mean, Packet Length Std, Packet Length Variance, PSH Flag Count, ACK Flag Count, Avg Bwd Segment Size, Init_Win_bytes_forward, min_seg_size_forward, Idle Mean, Idle Max, Idle Min

## Unknown-attack rule
A flow the classifier calls Benign becomes `Unknown-Anomaly` if the anomaly detector fires **or** the classifier is less than 90% sure.

| test set | value |
|---|---|
| attacks the classifier called Benign | 33 |
| … recovered by the rule | 66.7% |
| benign flows turned into alerts by the rule | 0.51% |
| anomaly detector alone: attacks flagged | 0.01% |
| anomaly detector alone: benign flagged | 0.48% |

The benign-only Isolation Forest contributes little on CIC-IDS2017: most attacks look normal flow-by-flow (DECISIONS.md D17). For attacks the model has never seen, see `reports/zero_day.md`.

## Quality gate
CI fails if macro-F1 < 0.9 or any attack class's recall < 0.9 (`tests/test_model_quality.py`).

## Limitations & risks
- CIC-IDS2017 is a 2017 lab capture: attack tools, traffic mix and the feature extractor version all shape what the model learns.
- Some classes may be recognised mostly by destination port (see `reports/shap_global.md`); a real attacker can change ports.
- Near-perfect test scores within one dataset do **not** imply the same on other networks; check `reports/cross_dataset.md`.
- Adversaries who know the features can shape traffic to evade detection.
- SHAP values show what the model relied on, not proof of malicious intent.
